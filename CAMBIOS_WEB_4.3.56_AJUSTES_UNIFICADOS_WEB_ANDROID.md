# SGF Web 4.3.56 · Ajustes unificados Web/Android

- Notificaciones, Alertas y Auditoría nunca muestran acción Editar.
- Login y recuperación usan el término Base de Datos; no exponen proveedor ni URL al usuario.
- Check-In muestra siempre Empresa asociada, Patente y Conductor en formulario, tablas y detalle.
- Botón Imprimir Check-In PDF disponible desde el detalle, con impresión del navegador / Guardar como PDF.
- Menú principal muestra Empresa Conectada encima de Hola.
- Conserva Performance Engine, Service Worker y seguridad Multiempresa de mapas.
